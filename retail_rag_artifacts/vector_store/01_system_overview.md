# Retail Inventory Optimization Agent — System Overview

## What this system is
A decision-support system that forecasts near-term SKU–store demand and translates it into replenishment recommendations with economic trade-offs.

## What it is not
- Not an automated purchasing system
- Not a finance or accounting system
- Not a guarantee of demand or profit

## Who uses it
Buyers, replenishment planners, operations leads, and finance partners.

## Core outputs
- Demand forecast
- Safety stock, reorder point, order quantity
- Working capital proxy
- Holding cost proxy
- Stockout penalty proxy
- Net value proxy
