# FAQ

## What does PD mean?
PD is the probability the borrower will default within 12 months.

## Why do we calculate ECL?
ECL translates PD into dollars using LGD and EAD so risk is financially interpretable.

## Is this tool making lending decisions?
No — it provides decision support. Human review is required for review/decline policies.

## What if the assistant can’t find evidence?
It must say “Not enough evidence in KB” and ask a specific follow-up question.
