# User Playbook (How to Use This Tool)

## Step 1 — Input scenario
Enter applicant, credit, loan terms, and macro context.

## Step 2 — Read the Decision Card
- PD: likelihood of default (probability, not certainty)
- ECL: expected loss in $
- Decision: recommended operational action

## Step 3 — Use reason codes
Reason codes explain the main drivers behind the recommendation.
Higher severity = more urgent risk.

## Step 4 — Apply next-best actions
- reprice or reshape offer for moderate risk
- manual review for borderline cases
- decline with clear eligibility pathway

## Step 5 — Ask the RAG assistant
Ask about:
- policy bands
- safe interpretation
- governance controls
- limitations and escalation rules
