# Monitoring & Drift (Recommended Operating Model)

## Key dashboards
- PD distribution over time
- ECL totals and ECL per booked loan
- approval / repricing / review / decline shares
- calibration curve (monthly/quarterly)
- top reason code frequencies

## Alerts (examples)
- PD mean shifts > X% vs baseline
- decline rate changes > X pp
- calibration degradation (Brier) > threshold
- spike in “macro stress” reason codes
