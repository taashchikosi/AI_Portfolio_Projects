# Model Evaluation Summary (Template)

This file should contain the final chosen metrics from your Phase 6 artifact (model comparison).

Recommended metrics:
- ROC-AUC
- PR-AUC (for class imbalance)
- Brier score (calibration)
- Confusion matrix at policy thresholds
- Stability: performance across segments (region, employment)

If you have a model_comparison CSV, summarize it here in plain English:
- why the champion model was selected
- trade-offs (performance vs explainability)
- calibration quality
